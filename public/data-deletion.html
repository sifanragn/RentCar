Data Deletion Instructions

Jika Anda ingin menghapus data akun Anda dari aplikasi HexaRent, ikuti langkah-langkah berikut:

1. Hapus Akun dari Aplikasi

Akses menu Profil → Pengaturan → Hapus Akun dalam aplikasi HexaRent.

2. Permintaan Penghapusan Manual

Jika Anda tidak dapat mengakses akun, kirim email ke:

support@hexarent.com

Dengan subjek: Data Deletion Request

3. Data yang Akan Dihapus

  • Data akun (nama, email, nomor telepon)
  • Dokumen upload (KTP & KK)
  • Data sosial media yang tertaut
  • Riwayat penyewaan & transaksi

Penghapusan data akan diproses maksimal 7 hari kerja.
